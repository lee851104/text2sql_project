    金鑰處理原則

    DEVELOPER API

    API 文件與接線範例

    所有查詢與管理功能都能透過相同的本機 HTTP API 使用。

    開啟互動文件

    ENDPOINTS

    POST/api/query GET/api/runtime/llm PUT/api/runtime/llm GET/api/data/* GET/api/corpus/entries GET/api/corpus/events POST/api/corpus/entries/{id}/review GET/api/training-status
    POST

    /api/query

    執行自然語言查詢，可逐次指定離線或線上模式。

    {
  "question": "2026年7月備轉容量率最低是哪一天？",
  "execution_mode": "offline"
}

    成功回應包含 SQL、欄位、列資料、圖表規格、統計與語意揭露。

    PUT

    /api/runtime/llm

    查看或切換預設執行模式。只有更新金鑰時才需傳 api_key。

    {
  "mode": "online",
  "model": "gpt-5.4-mini",
  "api_key": "<只傳給本機後端>"
}
    GET

    /api/data/status · changes · versions · events

    登入後調閱作用中資料檔、待審異動、不可變資料庫版本與完整稽核鏈；上傳、停用與審核端點均需 X-PowerQuery-CSRF。

    GET

    /api/corpus/entries?state=all

    登入管理工作階段後，調閱語料、審核狀態與不可變的來源資料檔紀錄。

    GET

    /api/corpus/events?limit=100

    調閱去識別的候選建立、驗證、審核、發布與工作區升版事件。

    POST

    /api/corpus/entries/{id}/review

    由登入人員核准或拒絕待審候選；審核身份由伺服器 session 決定，mutation 需附 CSRF header。

    {
  "decision": "approve",
  "note": "已核對 SQL、來源資料檔與驗證結果"
}
    GET

    /api/training-status

    取得索引進度、待處理數量與最近訓練時間；進行中時介面會自動更新。

    統一回應格式

    成功{ "success": true, "data": { … } }
    業務拒答{ "success": false, "error": "…" }
